\# Conceptualization



\## 1. Business Purpose

This system is designed to provide a convenient food ordering service for users.  

The main goal is to allow users to browse restaurants, select food items, and place orders easily through a mobile or web application.  



It also helps restaurants manage orders efficiently and increase sales.



---



\## 2. Problem Statement

Currently, ordering food can be inconvenient due to the following problems:



\- Users must visit restaurants or call manually  

\- Limited menu information  

\- Difficulty in comparing different restaurants  

\- Long waiting time for order processing  



Therefore, a digital food ordering system is needed to improve user experience and efficiency.



---



\## 3. System Overview

The system consists of two main actors:



\- User (Customer)

\- Admin (Restaurant or System Manager)



Main features:



\- User registration and login  

\- Browse restaurants and menus  

\- Place orders  

\- Payment processing  

\- Order tracking  

\- Admin manages menu and orders

\## 5. Concept of Operation



1\. User registers or logs into the system  

2\. User browses restaurants and menus  

3\. User selects food items and adds them to cart  

4\. User places an order  

5\. System processes payment  

6\. Restaurant receives the order  

7\. User tracks order status until delivery  



---



\## 6. Glossary



\- User: Customer who uses the application  

\- Admin: Person who manages the system or restaurant  

\- Order: A request made by the user for food  

\- Menu: List of food items available in a restaurant
